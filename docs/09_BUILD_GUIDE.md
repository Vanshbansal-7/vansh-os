# Master Instruction for Antigravity

You are not building a dashboard.

You are engineering a production-quality Personal Operating System called **Vansh OS (VOS)**.

Read every project document before writing any code.

Do not assume missing requirements.

If anything is unclear, ask before implementing.

Follow the Constitution, Product Bible, Design System, System Architecture, Feature Specifications, and Database Schema exactly.

Build feature-by-feature in the defined order.

Test after every feature.

Commit after every logical milestone.

Never sacrifice architecture for speed.

Never sacrifice user experience for convenience.

The finished product should feel like software built by a professional company—not a college project and not an AI-generated template.

End of Document.
